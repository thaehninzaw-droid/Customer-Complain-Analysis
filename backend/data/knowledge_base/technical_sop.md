# Technical Complaints - Standard Operating Procedure

## Scope
Covers internet outages, slow speeds, modem/router failures,
intermittent disconnects, and installation problems.

## Step 1 - Triage
1. Check the outage map / network status dashboard for the customer's
   area first - if there's a known area-wide outage, skip individual
   diagnostics and give the customer the outage ticket number and ETA
   instead.
2. If no known outage: run a remote line diagnostic (signal levels,
   modem uptime, recent reboot history).
3. Ask how long the issue has been happening and whether it's
   constant or intermittent - intermittent issues need a different
   diagnostic path (check for scheduled maintenance windows and
   weather-related line degradation) than a hard outage.

## Step 2 - Resolve or dispatch
- If the remote diagnostic finds a fixable issue (e.g. modem needs a
  remote reset, account provisioning mismatch): fix it live on the
  call/chat and confirm the customer's connection is back before
  closing.
- If the modem/router hardware appears faulty: offer a replacement
  shipped same-day, or a technician visit if self-install isn't
  practical for the customer.
- If a technician visit is needed: book the EARLIEST available slot,
  not just the next standard slot - repeat technical complaints
  (same customer, same issue, second+ time) should always get
  priority scheduling.

## Step 3 - Escalation criteria
Escalate to Network Engineering if:
- This is the customer's 3rd+ report of the same unresolved issue.
- A previously scheduled technician appointment was missed by the
  company (not the customer).
- The customer reports the outage is affecting their ability to work
  from home or run a business - flag as high-impact.

## Response time target
First response within 1 hour for active outages; technician dispatch
within 24-48 hours, expedited to same-day for repeat/high-impact cases.
